# strudel_starters

## a small repository of strudel starters to help folks practice and understand strudel more quickly!

### created for, and dedicated to the brave students in the GSU Computer Music Club

Anyone can use the materials that are found here. 

They are intended as starting points in strudel - additionally opening lines that can be freely modified and used for musical exploration and help with parsing the subtle complexities
of written code.
